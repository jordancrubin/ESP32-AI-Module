# ESP32-S3 AI Voice Assistant (Rubintech 2026)

A fully integrated AI Voice Assistant running on the ESP32-S3. This project combines local wake-word detection, cloud-based LLM intelligence (OpenAI/Local LLM), and text-to-speech into a standalone device with a touchscreen interface.

## Features

*   **Wake Word Detection:** Local, offline detection using Edge Impulse (default: "Hey Espy").
*   **Continuous Conversation:** Automatically loops between listening and speaking until silence is detected.
*   **LLM Integration:** Compatible with OpenAI API and local OpenAI-compatible endpoints (e.g., Ollama, LocalAI).
*   **Text-to-Speech (TTS):** Streams audio responses generated by the AI.
*   **Touchscreen UI:**
    *   **Clock Mode:** Shows time, date, WiFi signal, and local weather.
    *   **Main UI:** Volume control, voice selection, and status indicators.
    *   **Settings:** On-device configuration for WiFi and API keys via a captive web portal.
*   **Web Configuration:** Configure API keys, Timezone, Wake Sensitivity, Silence Threshold, and Weather settings via a web browser.
*   **Weather:** Real-time weather updates via OpenWeatherMap.

## Hardware Requirements

*   **MCU:** ESP32-S3 (N16R8 recommended for PSRAM).
*   **Display:** ILI9341 TFT Display (SPI).
*   **Touch:** XPT2046 Touch Controller (SPI).
*   **Microphone:** I2S MEMS Microphone (ICS-43434).
*   **Speaker:** I2S Amplifier (MAX98357A) + 4/8 Ohm Speaker.

## Installation & Setup

1.  **Build & Upload:**
    *   Open the project in VS Code with PlatformIO.
    *   Build and upload the firmware to your ESP32-S3.
    *   Upload the Filesystem Image (LittleFS) if required for assets (though most are generated on the fly).

2.  **First Boot:**
    *   The device will start in **Setup Mode** if no WiFi is configured.
    *   Connect to the WiFi hotspot named `ESP32-AI-Setup` (or similar, check serial logs).
    *   Navigate to `http://192.168.4.1` or `http://aiesp.local`.

3.  **Web Configuration:**
    *   **WiFi:** Enter your local network credentials.
    *   **API Config:** Enter your LLM API Key and URL (e.g., `http://192.168.1.50:11434/v1/chat/completions` for Ollama).
    *   **Timezone:** Select your local timezone string.
    *   **Weather:** Enter OpenWeatherMap API key and location (City,CC).
    *   **Thresholds:** Adjust Wake Word sensitivity (0.1-1.0) and Silence Threshold (amplitude).

## Usage

### Voice Interaction
1.  Say **"Hey Espy"** (or your trained wake word).
2.  The screen will flash white borders and show **"Listening..."**.
3.  Speak your query.
4.  The device will transcribe, think, and speak the response.
5.  It will immediately listen again for a follow-up.
6.  To stop, simply stop talking. After 3 seconds of silence, the session ends.

### Touch Controls
*   **Clock Screen:** Tap anywhere to wake up to the Main UI.
*   **Main UI:**
    *   **Volume Slider:** Adjust speaker volume.
    *   **Settings Icon:** Enter setup mode (starts Web Server).
    *   **List Icon:** Change Voice/Model settings.

## Serial Commands

You can control the device via USB Serial (115200 baud):

*   `/settings` - View current configuration and status.
*   `/calibrate` - Start touchscreen calibration routine.
*   `/reset_cal` - Reset calibration data.
*   `/test_mic` - Record 5 seconds of audio and play it back (hardware test).
*   `/say <text>` - Force TTS to speak the provided text.
*   `/new` - Clear conversation history.
*   `/voices` - Refresh available voices from the API.
